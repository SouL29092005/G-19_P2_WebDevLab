# G-19_P2_WebDevLab

### Environment Configuration (`.env`)

The environment configuration file is located at `.config/.env` in the project root directory.

Create a `.env` file inside `config/` with the following format:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_NAME=lab_reservation
DB_USER=postgres
DB_PASSWORD="your_postgres_password"
```
